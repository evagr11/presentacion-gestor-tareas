    Demostración · la hacemos en directo desde IntelliJ

    Guion de la demo

    1. Abrir la appSalen las tareas guardadas, ordenadas por prioridad y con colores. Las hechas van al final. VBox · ScrollPane
    2. BuscarEscribimos en el buscador y la lista se filtra al momento. TextField
    3. Crear una tarea«+ Nueva tarea»: título con contador, prioridad, horas y descripción con formato. Guardar con Ctrl+S. TextField · RadioButton · Spinner · HTMLEditor · MenuBar
    4. Editar y terminarPulsamos la tarea en la lista y la marcamos como hecha: pasa al final en gris. VBox
    5. Ver el resumenEn la pestaña «Resumen» el círculo muestra el porcentaje de tareas hechas. TabPane · ProgressIndicator
    6. Ocultar la listaVer → Ocultar lista de tareas cierra el panel izquierdo. SplitPane · MenuBar
    7. Cerrar y volver a abrirLas tareas siguen ahí porque se guardan en tareas.txt. Archivo → Salir

    VBox · MenuBar / Menu · SplitPane

    01/10

    VBox

    Eva Gallardo

    Contenedor que coloca a sus hijos uno debajo de otro, en columna. Es la raíz de la ventana, ordena el formulario de la tarea y guarda la lista de tareas, a la que añadimos un botón por tarea desde el controlador.

    Propiedades

    spacingSeparación entre un hijo y el siguiente (6 px en la lista).
    paddingMargen interior entre el borde y los hijos.
    alignmentCómo se alinean los hijos (TOP_LEFT, CENTER…).
    VBox.vgrowEn un hijo, hace que ocupe el alto sobrante (ALWAYS).

    Eventos y métodos

    • getChildren().add(nodo)Añade un hijo al final: un botón por tarea.
    • getChildren().clear()Vacía la lista antes de volver a pintarla.
    <VBox fx:id="vboxTareas" spacing="6.0">
   <children>
      <Label fx:id="lblSinTareas" text="No hay tareas..." wrapText="true" />
   </children>
   <padding>
      <Insets bottom="6.0" left="6.0" right="6.0" top="6.0" />
   </padding>
</VBox>
    private void mostrarLista() {
    vboxTareas.getChildren().clear();
    ...
}

private void anadirBoton(int posicion) {
    Button boton = new Button(texto);
    boton.setMaxWidth(Double.MAX_VALUE);   // ocupa todo el ancho
    boton.setOnAction(e -> cargarTarea(posicion));
    vboxTareas.getChildren().add(boton);
}

    MenuBar / Menu

    Eva Gallardo

    Barra de menús de la parte superior. Cada Menu (Archivo, Ver, Ayuda) contiene MenuItem, que son las opciones. Desde aquí se crea, guarda y elimina una tarea, se oculta la lista y se sale.

    Propiedades

    textTexto del menú o de la opción.
    acceleratorAtajo de teclado: Ctrl+N y Ctrl+S.
    disableDesactiva «Eliminar tarea» si no hay ninguna seleccionada.
    mnemonicParsingScene Builder lo pone a false en cada opción.

    Eventos y métodos

    • onActionMétodo que se ejecuta al elegir la opción.
    • setText() / setDisable()Cambian el texto o activan la opción desde el código.
    <MenuBar fx:id="barraMenu">
   <menus>
      <Menu mnemonicParsing="false" text="Archivo">
         <items>
            <MenuItem mnemonicParsing="false" onAction="#guardarTarea" text="Guardar tarea">
               <accelerator>
                  <KeyCodeCombination alt="UP" code="S" control="UP" meta="UP" shift="UP" shortcut="DOWN" />
               </accelerator>
            </MenuItem>
            <SeparatorMenuItem mnemonicParsing="false" />
            <MenuItem mnemonicParsing="false" onAction="#salir" text="Salir" />
         </items>
      </Menu>
   </menus>
</MenuBar>
    @FXML
private void salir(ActionEvent event) {
    Platform.exit();   // las tareas ya están guardadas
}

// al cargar una tarea se activa la opción del menú
itemEliminar.setDisable(false);

    SplitPane

    Eva Gallardo

    Divide la ventana en dos zonas con una barra que se puede arrastrar. A la izquierda está la lista de tareas y a la derecha las pestañas. Desde el menú Ver se puede cerrar la lista para tener más sitio.

    Propiedades

    dividerPositionsPosición del divisor de 0.0 a 1.0 (0.3 = 30 %).
    orientationHORIZONTAL (lado a lado) o VERTICAL.
    minWidth (hijo)Con 0 la zona izquierda se puede cerrar del todo.
    VBox.vgrowHace que el SplitPane ocupe todo el alto.

    Eventos y métodos

    • setDividerPositions(pos)Mueve el divisor: 0.0 oculta la lista, 0.3 la muestra.
    • getItems()Zonas que contiene.
    <SplitPane fx:id="divisor" dividerPositions="0.3" VBox.vgrow="ALWAYS">
   <items>
      <VBox minWidth="0.0" spacing="10.0"> ... </VBox>
      <TabPane fx:id="pestanas" tabClosingPolicy="UNAVAILABLE"> ... </TabPane>
   </items>
</SplitPane>
    @FXML
private void mostrarOcultarPanel(ActionEvent event) {
    if (panelVisible) {
        divisor.setDividerPositions(0.0);
        itemPanel.setText("Mostrar lista de tareas");
        panelVisible = false;
    } else {
        divisor.setDividerPositions(POSICION_DIVISOR);
        itemPanel.setText("Ocultar lista de tareas");
        panelVisible = true;
    }
}

    TextField

    Juan Cerrato

    Campo de texto de una línea. Lo usamos dos veces: para el título de la tarea, que es obligatorio y tiene 40 caracteres como máximo, y para el buscador, que filtra la lista mientras escribes.

    Propiedades

    textTexto escrito (getText / setText).
    promptTextTexto de ayuda en gris cuando está vacío.
    prefColumnCountAncho preferido en número de caracteres.
    editableSi es false no se puede escribir.

    Eventos y métodos

    • onKeyReleasedAl soltar una tecla: contamos caracteres o filtramos la lista.
    • onActionAl pulsar Intro en el título pasamos a la descripción.
    • positionCaret(n) / clear()Mueven el cursor o vacían el campo.
    <TextField fx:id="txtTitulo" onAction="#tituloIntro"
           onKeyReleased="#contarCaracteres"
           promptText="Ej.: Entregar las fichas de componentes" />

<TextField fx:id="txtBuscar" onKeyReleased="#buscar"
           promptText="Buscar tarea..." />
    @FXML
private void contarCaracteres(KeyEvent event) {
    String texto = txtTitulo.getText();
    if (texto.length() > MAX_CARACTERES_TITULO) {
        txtTitulo.setText(texto.substring(0, MAX_CARACTERES_TITULO));
        txtTitulo.positionCaret(MAX_CARACTERES_TITULO);
    }
    lblContador.setText(txtTitulo.getText().length() + " / 40 caracteres");
}

    RadioButton / ToggleGroup

    Juan Cerrato

    Botones de opción para elegir la prioridad: Alta, Media o Baja. El ToggleGroup los une para que solo pueda haber uno marcado. Cada uno lleva el color de su prioridad, el mismo que luego tiene la tarea en la lista.

    Propiedades

    text / textFillTexto y color del botón (rojo, ámbar, verde).
    toggleGroupGrupo al que pertenece el botón.
    selected«Media» empieza marcado.
    selectedToggle (grupo)Botón marcado del grupo.

    Eventos y métodos

    • onActionAl marcar un botón mostramos la prioridad elegida.
    • getSelectedToggle()Saber qué botón está marcado.
    • selectToggle(boton)Marcar uno desde el código al cargar una tarea.
    <RadioButton fx:id="rbAlta" mnemonicParsing="false" onAction="#cambioPrioridad"
             text="Alta" textFill="#c0392b">
   <toggleGroup>
      <ToggleGroup fx:id="grupoPrioridad" />
   </toggleGroup>
</RadioButton>
<RadioButton fx:id="rbMedia" mnemonicParsing="false" onAction="#cambioPrioridad"
             selected="true" text="Media" textFill="#b9770e" toggleGroup="$grupoPrioridad" />
    private String leerPrioridad() {
    if (grupoPrioridad.getSelectedToggle() == rbAlta) {
        return "Alta";
    } else if (grupoPrioridad.getSelectedToggle() == rbBaja) {
        return "Baja";
    } else {
        return "Media";
    }
}

    Spinner

    Juan Cerrato

    Campo con dos flechas para elegir un número sin escribirlo. Sirve para las horas estimadas de la tarea, de 1 a 20. Esas horas se suman en el resumen como horas pendientes.

    Propiedades

    min / maxValor mínimo y máximo (1 y 20).
    initialValueValor con el que empieza (1).
    amountToStepByCuánto sube o baja con cada flecha.
    editableSi se puede escribir el número a mano.

    Eventos y métodos

    • getValue()Lee las horas al guardar la tarea.
    • getValueFactory().setValue(n)Cambia el valor desde el código.
    • valueProperty()La enlazamos con un binding a una etiqueta.
    <Spinner fx:id="spHoras" amountToStepBy="1" initialValue="1"
         max="20" min="1" prefWidth="100.0" />
<Label fx:id="lblHoras" textFill="#808080" />
    @FXML private Spinner<Integer> spHoras;

public void initialize() {
    lblHoras.textProperty().bind(
        Bindings.concat("Has estimado ", spHoras.valueProperty(), " hora(s)"));
}

// al cargar una tarea
spHoras.getValueFactory().setValue(tarea.getHoras());

    TabPane

    José Antonio

    Contenedor con pestañas. Solo se ve el contenido de la pestaña elegida. Tenemos «Tarea», con el formulario, y «Resumen», con el progreso. Al entrar en «Resumen» se recalculan los datos.

    Propiedades

    tabClosingPolicyUNAVAILABLE: las pestañas no se pueden cerrar.
    sideLado donde salen las pestañas (TOP por defecto).
    text (Tab)Título de cada pestaña.
    content (Tab)Lo que muestra cada pestaña.

    Eventos y métodos

    • onSelectionChangedSe lanza al entrar y al salir de la pestaña.
    • isSelected()Comprueba si la pestaña está activa.
    <TabPane fx:id="pestanas" tabClosingPolicy="UNAVAILABLE">
   <tabs>
      <Tab fx:id="tabTarea" text="Tarea">
         <content> ... </content>
      </Tab>
      <Tab fx:id="tabResumen" onSelectionChanged="#cambioPestana" text="Resumen">
         <content> ... </content>
      </Tab>
   </tabs>
</TabPane>
    @FXML
private void cambioPestana(Event event) {
    if (tabResumen.isSelected()) {   // solo al entrar
        actualizarResumen();
    }
}

    ScrollPane

    José Antonio

    Muestra un único contenido y añade barras de desplazamiento cuando no cabe. Envuelve la lista de tareas: con muchas tareas aparece la barra vertical, nunca la horizontal.

    Propiedades

    contentLo que se desplaza: el VBox de tareas.
    fitToWidthAjusta el ancho del contenido al del ScrollPane.
    hbarPolicy / vbarPolicyCuándo se ve cada barra (NEVER, AS_NEEDED…).
    vvaluePosición vertical, de 0.0 (arriba) a 1.0 (abajo).

    Eventos y métodos

    • setVvalue(0.0)Vuelve arriba cada vez que se pinta la lista.
    • onScrollEvento al desplazar (no lo hemos necesitado).
    <ScrollPane fx:id="scrollTareas" fitToWidth="true" hbarPolicy="NEVER" VBox.vgrow="ALWAYS">
   <content>
      <VBox fx:id="vboxTareas" spacing="6.0"> ... </VBox>
   </content>
</ScrollPane>
    private void mostrarLista() {
    vboxTareas.getChildren().clear();
    // ... añadimos un botón por tarea ...

    // ScrollPane: volvemos arriba del todo
    scrollTareas.setVvalue(0.0);
}

    HTMLEditor

    Jesús Seco

    Editor de texto con barra de herramientas: negrita, cursiva, listas, colores… Guarda el texto como HTML. Es la descripción de cada tarea y se guarda tal cual en el fichero.

    Propiedades

    htmlTextContenido del editor en HTML.
    prefHeightAlto preferido (200 px).
    VBox.vgrowOcupa el espacio sobrante del formulario.
    disableDesactiva el editor y su barra.

    Eventos y métodos

    • getHtmlText()Devuelve el contenido en HTML para guardarlo.
    • setHtmlText(html)Carga una descripción o la vacía con "".
    • requestFocus()Pone el cursor en el editor.
    <?import javafx.scene.web.HTMLEditor?>

<HTMLEditor fx:id="editorDescripcion" prefHeight="200.0" VBox.vgrow="ALWAYS" />
    // guardar
String descripcion = editorDescripcion.getHtmlText();

// cargar una tarea
editorDescripcion.setHtmlText(tarea.getDescripcion());

// nueva tarea
editorDescripcion.setHtmlText("");

    ProgressIndicator

    Jesús Seco

    Indicador circular que muestra un porcentaje. En la pestaña «Resumen» enseña qué parte de las tareas está hecha. Se actualiza al crear, marcar o eliminar una tarea.

    Propiedades

    progressValor de 0.0 a 1.0; negativo = gira sin parar.
    prefWidth / prefHeightTamaño del círculo (170 × 170).
    indeterminateSolo lectura: true si el progreso es desconocido.
    visibleMostrarlo u ocultarlo.

    Eventos y métodos

    • setProgress(valor)Cambia el porcentaje que se muestra.
    • getProgress()Lee el valor actual.
    <ProgressIndicator fx:id="indicadorProgreso" prefHeight="170.0"
                   prefWidth="170.0" progress="0.0" />
    double progreso = 0.0;
if (total > 0) {
    progreso = (double) hechas / total;   // sin el (double) daría 0
}
indicadorProgreso.setProgress(progreso);

    Lo que nos costó y dónde lo aprendimos

    Dificultades

    • El atajo de teclado de un MenuItem no se escribe como texto: es un KeyCodeCombination con todas las teclas modificadoras.
    • El Spinner no tiene setValue(): hay que pasar por getValueFactory().
    • onSelectionChanged de una pestaña se lanza al entrar y al salir, así que hay que comprobar isSelected().
    • Al dividir dos int el progreso siempre daba 0: hay que convertir a double.
    • El HTMLEditor necesita el módulo javafx.web. Con JDK 24 o superior además hace falta JavaFX 25, que trae jdk.jsobject.
