# Gestor de tareas · Grupo C

Página de la exposición del Grupo C (Desarrollo de Interfaces, 2º DAM): la aplicación JavaFX
«Gestor de tareas», el guion de la demo y los 10 componentes (MenuBar/Menu, RadioButton/ToggleGroup,
TextField, VBox, TabPane, Spinner, ScrollPane, HTMLEditor, ProgressIndicator y SplitPane) con su
código FXML y del controlador.

Se navega con scroll o con las flechas ← → del teclado.
